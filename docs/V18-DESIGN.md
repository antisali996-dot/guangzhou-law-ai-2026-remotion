# v18：基于原片的优化

本版沿用原项目的人物骨骼、骑楼、单车、手机动作、杯子轨迹及 84 秒中文旁白。没有采用此前弃用的整套动漫人物/背景方案。

## 改动

- 片头换成与原片相近的车筐破损特写，放大题目与冲突。该图仅用于开场插入画面，不代替人物动作。
- 法条段将解释标题与原文节选分开，一次突出正在讲述的一条。保留“经调查难以确定”“证明不是自己”“可能加害的使用人”“情节严重”等条件及法条出处。
- 原有窗格图解继续承担排除、补偿和追偿的演示；增加禁止抛物、刑责条件和刑罚的简洁代码图形。
- 证据板增加主标题，放大监控画面，去掉缩放后容易干扰辨识的扫描线。
- 原人物只增加短暂、少量的眨眼，不改变手把接触、步态、手机取放和离场速度。
- 调整夜景叠色和暗角，改用稳定的低对比纸纹，去掉逐帧变换间距的点状颗粒。

## 美术资源来源

两项新增资源均使用内置 **GPT imagegen**，没有从网上下载图片：

1. `public/film-v18/basket-detail.png`：以 v16 成片 2.5 秒画面为参考生成的局部特写，约束保留黑色硬塑车筐、纵向槽、裂口、灰绿湿地与克制的原片色调，不生成角色，不使用动漫人脸或金色夕阳。
2. `public/film-v18/paper-texture.png`：均匀、低对比、无文字与折痕的浅色纸纹。

完整提示词保存在 `public/film-v18/asset-manifest.json`。两项素材均已复制进本项目，未依赖生成工具的缓存路径。
