# 法条核对记录


民事责任画面与现有旁白所依据的条文为《民法典》第1254条第一款。本轮将画面末句恢复为“可能加害的建筑物使用人补偿后，有权向侵权人追偿。”并标注节选。现有旁白使用了语义承接的简写，本轮未重录声音，未把其标为逐字原文。官方公开文本见[福州市不动产登记和交易中心发布的《中华人民共和国民法典》](https://bdcdj.fuzhou.gov.cn/zwgk/fgwj/202006/t20200609_3302468.htm)。

刑事责任画面和现有旁白对应《刑法》第291条之二第一款，保留“情节严重的”条件，并将出处注明第一款。官方公开文本见[国家市场监督管理总局《中华人民共和国刑法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2025/art_890f1333b6284c3cbb225c3cd2647c4b.html)。

本轮未核验全部素材和配音的版权/授权链；未进行人工主观听审。最终声音时序、可识别性与响度以交付 MP4 的解码结果为准，不以响度单项代替声音完整性。
